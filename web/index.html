  Privacy policy
  

    
What this tool does with your data

    
Golden Hour is a document-preparation tool, not a filing service. It
    does not submit anything to police, banks, or any authority on your
    behalf. You review and submit the generated documents yourself.


    
What is stored

    
Nothing, persistently. Evidence you paste or upload
    (chat text, bank SMS, screenshots, your name/contact details) is held in
    memory only for the duration of processing your request and is discarded
    once the response is sent back to your browser. This server does not
    write your evidence to a database, a log file, or a disk. Closing or
    refreshing this page removes everything from your browser too.


    
Where your data travels during processing

    
    
      
  • To Google's Gemini API — the text and any
      screenshots that could not be read locally are sent to Google for
      analysis, subject to Google's own API data-handling terms. Google's
      API terms (at the time of writing) state that data sent via the API is
      not used to train their models by default for paid tiers; verify the
      current terms for the tier this deployment uses.
    • 
      
  • Nowhere else. No analytics, no third-party
      trackers, no advertising networks, no data brokers.
    • 
    


    
The cryptographic seal

    
Each analysis produces a Merkle root (a hash-based fingerprint) of
    the evidence bundle, generated inside this request and returned to you.
    The seal is derived from your data but does not itself reveal document
    contents — it is used to detect later tampering, not to identify you.
    It is not stored server-side either.


    
Complainant details (name, mobile, email, address)

    
Collected only to pre-fill the generated complaint documents. Used
    for nothing else, sent nowhere except into the documents shown to you
    and, if included in the evidence text, to the Gemini API as part of
    that analysis.


    
This is a student project

    
Golden Hour is an academic project, not a commercial or government
    service. It has not undergone formal security audit or legal review.
    Do not paste information you are not comfortable sending to Google's
    API for processing. If you are in the middle of an active fraud, treat
    the "Do this first" guidance as a starting point, not a substitute for
    contacting your bank and 1930 directly.
